# clickup-cli

A Rust CLI for the ClickUp API, built for AI agents — the ClickUp counterpart to
[netsuite-cli](https://github.com/CreativePlanningBusinessServices/netsuite-cli) and `intacct-cli`.

Goal: cover the actions available in the ClickUp API
([reference](https://developer.clickup.com/reference/getaccesstoken)) as composable subcommands
with JSON output, plus a bundled agent skill under `skills/` describing how to drive it.

Status: scaffold. See ClickUp task
[868k5a5wa](https://app.clickup.com/t/868k5a5wa).
